# AI provenance

The original reverse engineering, additive patch implementation, FFmpeg build work, and initial documentation were produced with Claude Code and are described in the project history and `docs/notes/`.

The v0.2 lifecycle hardening, auto-control interface, systemd integration, installation layout, and associated tests were implemented with OpenCode's `space-bunny-free` model under direct user supervision. The code was reviewed and tested locally; AI output is not a substitute for the user's review.

No part of DaVinci Resolve is included in this repository. The project modifies a copy already installed by the user and preserves the upstream project's MIT license.
